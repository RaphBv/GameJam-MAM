# GameJam-MAM

A game Jam project where the theme was wedding. We made a game where the stepmom is here to ruin the wedding, so the husband has to repair the stepmom's actions in a giving time to win. If the stepmom destroys everything she wins, but if you can repair all the things she did, you win
